Déployer Paperkeep sur les ordinateurs d'un cabinet (Chrome et Edge)

Mis à jour le 2026-10-28 · Paperkeep

Dans un cabinet comptable ou une PME dont les postes sont gérés, les utilisateurs ne peuvent pas toujours installer une extension eux-mêmes. L'administrateur peut alors l'installer d'office sur tous les postes avec la règle ExtensionInstallForcelist, qui existe dans Chrome et dans Microsoft Edge. Voici les valeurs à utiliser pour Paperkeep, d'après les documentations officielles de Google et de Microsoft.

Aller à : Avant de commencer · Les identifiants · Chrome · Edge · Vérifier

1. Avant de commencer : aucune donnée centralisée

  • Pas de console, pas de serveur. Paperkeep n'a pas de serveur. Chaque poste garde ses factures dans son propre dossier Téléchargements › Factures. Rien ne remonte vers le cabinet ni vers nous.
  • Rien à configurer côté Paperkeep. La règle installe l'extension ; l'utilisateur s'en sert ensuite comme d'habitude : il ouvre une page de facturation et clique sur l'icône.
  • Les permissions restent les mêmes. Les accès facultatifs (portails Stripe, reçus sans PDF, HBO Max) sont toujours demandés au clic, seulement si la page en a besoin. Le détail : Vérifiez Paperkeep vous-même.
  • La Pro reste individuelle. La règle n'active aucune licence : chaque utilisateur qui veut la Pro la démarre depuis l'extension.
  • Testez d'abord sur un poste. Google le rappelle pour le registre : une modification mal faite peut endommager un ordinateur.

Chaque valeur est l'identifiant de l'extension suivi, après un point-virgule, de l'adresse de mise à jour du store. Si l'adresse est omise, chaque navigateur utilise par défaut celle de son propre store.

3. Google Chrome

Avec une stratégie de groupe (Windows)

  1. Si les règles de Chrome n'apparaissent pas dans l'éditeur de stratégie de groupe, téléchargez les derniers modèles de règles fournis par Google (fichier policy_templates.zip).
  2. Dans l'éditeur, ouvrez Modèles d'administration › Google › Google Chrome › Extensions.
  3. Ouvrez la règle qui configure la liste des extensions installées d'office (ExtensionInstallForcelist, « Configure the list of force-installed apps and extensions » dans les modèles en anglais), activez-la et ajoutez la valeur Chrome du tableau.

Autre possibilité : la règle ExtensionSettings

Google documente aussi cette règle, au format JSON, à saisir sur une seule ligne dans « paramètres de gestion des extensions » :

{"mmllhnjkdpilogbaokplljippcnmdopi":{"installation_mode":"force_installed","update_url":"https://clients2.google.com/service/update2/crx"}}

Avec force_installed, l'utilisateur ne peut pas désactiver l'extension. Avec normal_installed, elle est installée automatiquement mais l'utilisateur peut la désactiver. Si les deux règles sont définies, ExtensionSettings l'emporte sur ExtensionInstallForcelist.

Par le registre

Les règles de Chrome se trouvent sous HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome. Google conseille cette voie pour les ordinateurs qui ne sont pas joints à un domaine Active Directory, et fournit un exemple de fichier chrome.reg dans le paquet Chrome Enterprise, à adapter et à tester avant de le déployer.

À savoir

  • Une extension installée par cette règle ne peut être ni désinstallée ni désactivée par l'utilisateur. La retirer de la liste la désinstalle.
  • La règle ne s'applique pas à la navigation privée.
  • La restriction aux postes gérés (domaine, MDM…) vise les extensions hors Chrome Web Store. Paperkeep est publié sur le Chrome Web Store.

4. Microsoft Edge

Avec une stratégie de groupe (Windows)

  1. Téléchargez les modèles d'administration de Microsoft Edge depuis la page Microsoft Edge Enterprise et copiez msedge.admx (et le fichier .adml de votre langue) dans le dossier des définitions de stratégie.
  2. Dans l'éditeur, ouvrez Computer Configuration (ou User Configuration) › Policies › Administrative Templates › Microsoft Edge › Extensions. Ce sont les libellés anglais de la documentation de Microsoft ; un Windows en français les traduit.
  3. Ouvrez « Control which extensions are installed silently » (nom de la règle dans les modèles en anglais), activez-la et ajoutez la valeur Edge du tableau.

Par le registre

Clé : HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist. Chaque extension est une valeur de type REG_SZ nommée 1, 2, 3… Exemple :

SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist\1 = ekoobifejmegpmndflgdcepbldfbegki;https://edge.microsoft.com/extensionwebstorebase/v1/crx

Sur Mac

Clé de préférence ExtensionInstallForcelist, sous forme de tableau (<array>) contenant la valeur Edge du tableau.

À savoir

  • Sur un Windows qui n'est pas joint à un domaine Active Directory, l'installation forcée est limitée aux extensions publiées sur Edge Add-ons. C'est le cas de Paperkeep.
  • L'utilisateur ne peut ni désinstaller ni désactiver l'extension. La retirer de la liste la désinstalle.
  • La règle ne s'applique pas au mode InPrivate.
  • Au 26/10/2026, la version publiée sur Edge Add-ons est la 1.4.2 (mise à jour du 17/10/2026). Les postes reçoivent les versions suivantes automatiquement, par le store.

Firefox a ses propres règles d'entreprise, que cette page ne couvre pas.

5. Vérifier que la règle est appliquée

  • Chrome : ouvrez chrome://policy, cliquez sur Actualiser les règles et vérifiez que l'état de la règle est « OK ». Les utilisateurs doivent redémarrer Chrome pour que la modification prenne effet.
  • Edge : ouvrez edge://policy pour voir les règles appliquées. Pour forcer la mise à jour des stratégies de groupe sur un poste : gpupdate /force, puis fermez et rouvrez Edge.
