Odoo : comment y envoyer vos factures fournisseurs (et celles qui n'arrivent pas toutes seules)

Odoo Comptabilité reçoit vos factures fournisseurs par Peppol, par l'alias e-mail d'un journal d'achats ou par simple glisser-déposer. Les factures de vos abonnements en ligne facturés depuis l'étranger, elles, ne viennent que si quelqu'un va les chercher. Voici les étapes d'après la documentation officielle d'Odoo (version 20.0), puis la façon de combler ce manque.

Aller à : Peppol · Par e-mail · Import manuel · Ce qui n'arrive pas tout seul · Avec Paperkeep

1. Par Peppol : les factures de vos fournisseurs belges

La documentation indique qu'Odoo « agit à la fois comme point d'accès et comme SMP », et que l'enregistrement Peppol est gratuit, y compris dans Odoo Community. On s'inscrit avec le bouton Activer Peppol ; l'inscription est en principe activée dans la journée. Une partie des écrans de configuration Peppol reste en anglais dans la documentation française : nous ne les reprenons pas ici.

Source : documentation officielle d'Odoo, facturation électronique, consultée le 25/10/2026.

2. Par e-mail : l'alias du journal Factures fournisseurs

  1. Un domaine d'alias doit être configuré dans votre base.
  2. L'adresse par défaut vendor-bills@ suivie de votre domaine d'alias est créée automatiquement, dans l'onglet Paramètres avancés du journal Factures fournisseurs.
  3. Pour la modifier : Comptabilité ‣ Configuration ‣ Journaux, choisissez le journal, puis changez l'Alias d'e-mail dans l'onglet Paramètres avancés.

Chaque PDF joint à l'e-mail devient un brouillon de facture fournisseur. Seuls les PDF et les XML sont traités par l'alias d'un journal ; les JPEG passent par l'application Documents. La reconnaissance automatique du contenu (numérisation) consomme des crédits payants, sauf pour les fichiers XML.

Source : documentation officielle d'Odoo, numérisation des factures, consultée le 25/10/2026.

3. Import manuel : un PDF déjà sur votre ordinateur

Dans le tableau de bord de Comptabilité, glissez-déposez les factures dans le journal d'achats voulu, ou cliquez sur le bouton de téléchargement de ce journal (« Télécharger » dans la documentation française).

Source : documentation officielle d'Odoo, consultée le 25/10/2026.

4. Ce qui n'arrive pas tout seul

Peppol n'apporte que les factures de fournisseurs qui y sont soumis. Les fournisseurs établis à l'étranger sans établissement stable en Belgique ne le sont pas (voir ce que dit la règle). Et beaucoup d'abonnements en ligne n'envoient pas leur facture en pièce jointe : elle attend dans l'espace « Facturation » du compte. L'alias vendor-bills@ ne reçoit donc rien de leur part.

Exemples : ChatGPT, Canva, Meta Ads, Google Workspace, Adobe, LinkedIn Premium. Le chemin exact pour chacun est dans Où trouver la facture de ChatGPT, Canva, Google Workspace…

5. Avec Paperkeep

  1. Ouvrez la page de facturation du service.
  2. Cliquez sur l'icône Paperkeep, puis sur « Télécharger » : les factures arrivent en PDF dans Téléchargements › Factures, nommées par date, fournisseur et montant.
  3. Glissez-les dans le journal d'achats d'Odoo, ou envoyez-les en pièces jointes à l'alias vendor-bills@ : un PDF, un brouillon de facture.

Ce que Paperkeep ne fait pas : il ne se connecte pas à Odoo, n'envoie rien tout seul et ne demande aucun mot de passe. Il n'a aucun partenariat avec Odoo. Rien ne quitte votre ordinateur.

Paperkeep est gratuit, sans limite de téléchargement. Paperkeep Pro (39 € par an TVA comprise, essai gratuit de 14 jours, satisfait ou remboursé 30 jours) ajoute la tournée du mois, les factures manquantes et le récapitulatif pour le comptable.
