Facture Uber : le reçu n'est pas la facture (et comment y mettre votre TVA)

Après une course, Uber vous envoie un reçu. Ce reçu n'est pas la facture : celle-ci se télécharge sur le site riders.uber.com. Et elle ne porte vos données d'entreprise (nom, adresse, numéro de TVA) que si vous les avez saisies dans votre profil fiscal avant la course. Voici les deux étapes, d'après l'aide officielle d'Uber.

Étape 1 : ajouter vos données d'entreprise (une seule fois)

  1. Sur riders.uber.com, ouvrez la page des profils fiscaux : riders.uber.com/tax-profiles.
  2. Dans Tax profile, choisissez Business tax info (libellés en anglais sur l'aide).
  3. Indiquez le nom, l'adresse et le VAT number, puis validez.

Ce que dit l'aide : « Les factures ne peuvent pas être modifiées une fois les courses effectuées. » Les données ne valent donc que pour les courses suivantes.

Source : aide officielle d'Uber, données fiscales (en anglais) et facture de course, consultées le 25/10/2026.

Étape 2 : télécharger la facture

  1. Connectez-vous sur riders.uber.com et ouvrez Mes courses.
  2. Choisissez la course.
  3. Cliquez sur Afficher les détails.
  4. Cliquez sur Télécharger la facture, en haut à droite.

À savoir : l'aide indique « Nous nous efforçons de rendre les factures disponibles via l'application Uber » ; pour l'instant, passez par le site.

Source : aide officielle d'Uber, consultée le 25/10/2026.

Le reçu, si c'est lui qu'il vous faut

Dans l'application : Activité › la course › Reçu › Télécharger au format PDF (ou Renvoyer un e-mail).

Source : aide officielle d'Uber, reçu de course, consultée le 25/10/2026.

Avec Paperkeep

Ouvrez le détail de la course sur riders.uber.com, cliquez sur l'icône Paperkeep (extension gratuite pour Chrome, Edge et Firefox) puis sur « Télécharger ». Paperkeep sait cliquer sur un bouton « Télécharger la facture » ; nous ne l'avons pas encore testé sur un vrai compte Uber. Le PDF arrive dans Téléchargements › Factures, nommé par date, fournisseur et montant. Rien ne quitte votre ordinateur. Un problème ? Écrivez-nous à contact@paperkeep.be.

Questions fréquentes

Le reçu Uber suffit-il pour ma comptabilité ?

Uber distingue les deux documents : c'est la facture qui reprend le profil fiscal que vous avez saisi. Demandez à votre comptable lequel il veut, et gardez la facture si vous voulez faire valoir la TVA.

J'ai oublié d'ajouter mon numéro de TVA avant la course. Puis-je corriger ?

Non : selon l'aide d'Uber, les factures ne peuvent pas être modifiées une fois les courses effectuées. Ajoutez votre profil fiscal maintenant, il servira pour les prochaines.

Pourquoi je ne trouve pas la facture dans l'application ?

Parce que l'aide d'Uber indique que la facture se télécharge sur le site riders.uber.com ; Uber dit travailler à la rendre disponible dans l'application.

Ajouter son numéro de TVA chez d'autres services : Google, Apple, Uber… Les autres services : où trouver la facture de ChatGPT, Canva, Google Workspace et sept autres.
