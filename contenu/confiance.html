Vérifiez Paperkeep vous-même

Une extension qui lit vos pages de facturation doit pouvoir être contrôlée sans qu'on la croie sur parole. Voici ce que Paperkeep lit, ce qu'il ne lit pas, chaque permission qu'il demande et pourquoi, et comment le vérifier vous-même dans votre navigateur.

Cette page décrit la version 1.5.3 de l'extension, d'après son code relu le 26/10/2026. Le numéro de la version installée chez vous s'affiche dans la page des extensions de votre navigateur.

Aller à : Ce qu'il lit · Ce qu'il ne lit pas · Ce qui reste chez vous · Les permissions · La Pro et ExtensionPay · Le code source · Vérifier dans le navigateur

1. Ce que Paperkeep lit

  • Rien, tant que vous ne cliquez pas sur son icône. L'extension ne déclare aucun script qui tourne en permanence sur les sites et ne demande l'accès à aucun site à l'installation.
  • Au clic, la page ouverte, et elle seule. Paperkeep y repère les liens de facture, les dates, les montants et le nom du fournisseur, pour proposer la liste des factures à télécharger.
  • Avec la Pro, dans Gmail : le message ouvert au moment du clic (expéditeur, objet, date, pièces jointes PDF). Pas les autres messages de votre boîte.
  • Les fichiers de facture eux-mêmes : ils sont téléchargés depuis le site du fournisseur directement vers votre dossier Téléchargements › Factures. Paperkeep vérifie ensuite la taille et le type de chaque fichier, pour signaler un téléchargement vide ou erroné.

2. Ce que Paperkeep ne lit pas et ne fait pas

  • Il ne lit ni vos autres onglets, ni votre historique, ni vos mots de passe. Il ne se connecte à aucun compte à votre place.
  • La version gratuite ne lit pas vos e-mails.
  • Il n'envoie ni facture, ni contenu de page, ni liste de fournisseurs, ni à nous ni à un tiers. Paperkeep n'a pas de serveur et l'extension ne contient aucun outil de statistiques.
  • Il n'envoie rien à un logiciel comptable : c'est vous qui transmettez les fichiers.

Deux pages de ce site s'ouvrent d'elles-mêmes : une page de premiers pas à l'installation, et une page d'au revoir à la désinstallation. Ce sont des pages statiques, sans formulaire caché ni paramètre ajouté à l'adresse.

3. Ce qui reste sur votre ordinateur

Paperkeep garde quelques données dans le stockage local de l'extension, sur votre ordinateur :

  • le journal de vos 500 derniers téléchargements (fournisseur, nom du fichier, résultat de la vérification) ;
  • la liste de vos fournisseurs, avec l'adresse de leur page de facturation sans ses paramètres (ils portent souvent un jeton), pour la tournée du mois ;
  • vos réglages et un compteur de téléchargements par mois ;
  • avec la Pro, le dernier état connu de votre abonnement.

La bibliothèque de paiement ExtensionPay range en plus, dans le stockage synchronisé du navigateur, la date d'installation et, dès que vous avez cliqué sur une offre Pro, votre identifiant de licence. Si la synchronisation de votre navigateur est activée, ces deux valeurs suivent votre compte de navigateur.

4. Les permissions, une par une

À l'installation, Paperkeep demande quatre permissions. Les autres sont facultatives : elles ne sont demandées qu'au moment où vous cliquez sur « Télécharger », et seulement si la page en a besoin. Si vous refusez, rien n'est téléchargé et rien d'autre ne change.

5. Paperkeep Pro : seul l'état de l'abonnement est vérifié

Pourquoi la fiche du Chrome Web Store cite des données personnelles, de paiement et le « contenu de site web » ? Google demande de déclarer tout ce que l'extension manipule, même sur votre ordinateur. Le contenu de la page de facturation est lu sur votre ordinateur, au clic, et n'est envoyé nulle part. L'adresse e-mail et le paiement ne concernent que la Pro, chez ExtensionPay et Stripe.

  • L'abonnement Pro passe par ExtensionPay, avec un paiement chez Stripe. L'extension interroge extensionpay.com pour une seule chose : l'état de votre abonnement (payé, essai en cours). Aucune facture et aucun contenu de page n'y sont envoyés.
  • Tant que vous n'avez cliqué sur aucune offre Pro (essai, paiement ou connexion), aucun identifiant n'existe chez ExtensionPay et l'extension ne lui envoie aucune requête.
  • Sans connexion internet, le dernier état connu reste valable 7 jours.
  • Sur Firefox, uniquement après votre accord. La version Firefox déclare deux types de données facultatifs, l'identité (e-mail et identifiant chez ExtensionPay) et le paiement (chez Stripe). Firefox ne les affiche pas à l'installation : ils vous sont demandés au premier clic sur la Pro. Sans cet accord, rien n'est envoyé à ExtensionPay. Vous pouvez le retirer à tout moment dans about:addons, dans la section des permissions et des données des réglages de l'extension (« Permissions and data » dans la documentation de Mozilla).

Source : Extension Workshop, consentement à la collecte de données dans Firefox (mise à jour du 18/10/2026), consultée le 26/10/2026.

6. Le code est lisible dans votre navigateur

Le code de l'extension que vous installez est lisible dans votre propre navigateur : dans chrome://extensions, activez le « Mode développeur », puis ouvrez le service worker de Paperkeep avec « Inspecter les vues » : vous voyez exactement ce qui s'exécute, et l'onglet Réseau montre chaque requête.

7. Vérifier vous-même dans le navigateur

Les permissions accordées (Chrome)

  1. Ouvrez le menu Plus de Chrome, puis Extensions, puis Gérer les extensions.
  2. Sur Paperkeep, cliquez sur Détails.
  3. La section des autorisations montre ce qui a été accordé. Pour l'accès aux sites, Chrome propose « En cas de sélection », « Sur des sites spécifiques » et « Sur tous les sites ».

Sur Firefox, les permissions et l'accord pour les données de la Pro se trouvent dans about:addons, dans les réglages de l'extension.

Les requêtes envoyées (Chrome)

  1. Tapez chrome://extensions dans un nouvel onglet.
  2. Activez l'interrupteur Mode développeur (« Developer mode »).
  3. Sur la carte de Paperkeep, cliquez sur le lien bleu à côté de Inspecter les vues (« Inspect views »). Les outils de développement s'ouvrent : choisissez l'onglet Network (Réseau).
  4. Pour la fenêtre de Paperkeep elle-même, inspectez-la (clic droit dans la fenêtre, puis Inspecter) et rechargez depuis l'onglet Network.
  5. Utilisez Paperkeep normalement. Vous ne verrez que des requêtes vers le site du fournisseur dont vous téléchargez les factures et, si vous utilisez la Pro, vers extensionpay.com.

Sources : documentation officielle de Chrome, page des extensions et mode développeur et inspecter le service worker, la fenêtre et le réseau ; aide du Chrome Web Store, gérer ses extensions. Consultées le 26/10/2026. Les libellés français des outils de développement peuvent varier selon la langue de votre navigateur.
