Paperkeep uitrollen op de computers van een kantoor (Chrome en Edge)

In een boekhoudkantoor of een kmo met beheerde computers kunnen gebruikers niet altijd zelf een extensie installeren. De beheerder kan ze dan op alle toestellen verplicht installeren met het beleid ExtensionInstallForcelist, dat zowel in Chrome als in Microsoft Edge bestaat. Hier vind je de waarden voor Paperkeep, volgens de officiële documentatie van Google en Microsoft.

Ga naar: Vooraf · De ID's · Chrome · Edge · Controleren

1. Vooraf: geen centrale gegevens

  • Geen console, geen server. Paperkeep heeft geen server. Elke computer bewaart zijn facturen in zijn eigen map Downloads › Factures. Niets gaat naar het kantoor of naar ons.
  • Niets in te stellen bij Paperkeep. Het beleid installeert de extensie; de gebruiker werkt er daarna mee zoals altijd: facturatiepagina openen en op het icoon klikken.
  • De machtigingen blijven dezelfde. De optionele toegangen (Stripe-portalen, betalingsbewijzen zonder pdf, HBO Max) worden nog altijd bij de klik gevraagd, en alleen als de pagina ze nodig heeft. Details: Controleer Paperkeep zelf.
  • Pro blijft individueel. Het beleid activeert geen licentie: wie Pro wil, start die zelf vanuit de extensie.
  • Test eerst op één toestel. Google waarschuwt voor het register: een foute wijziging kan een computer beschadigen.

3. Google Chrome

Met een groepsbeleid (Windows)

  1. Verschijnen de Chrome-regels niet in de groepsbeleidseditor, download dan de nieuwste beleidssjablonen van Google (bestand policy_templates.zip).
  2. Open in de editor Administrative Templates › Google › Google Chrome › Extensions (Engelse labels uit de hulp van Google; een Nederlandstalige Windows vertaalt ze).
  3. Open het beleid voor de lijst met verplicht geïnstalleerde extensies (ExtensionInstallForcelist, « Configure the list of force-installed apps and extensions »), schakel het in en voeg de Chrome-waarde uit de tabel toe.

Andere mogelijkheid: het beleid ExtensionSettings

Google documenteert ook dit beleid, in JSON op één regel, in « Extension management settings »:

{"mmllhnjkdpilogbaokplljippcnmdopi":{"installation_mode":"force_installed","update_url":"https://clients2.google.com/service/update2/crx"}}

Met force_installed kan de gebruiker de extensie niet uitschakelen. Met normal_installed wordt ze automatisch geïnstalleerd, maar kan de gebruiker ze uitschakelen. Zijn beide beleidsregels ingesteld, dan heeft ExtensionSettings voorrang op ExtensionInstallForcelist.

Via het register

De Chrome-regels staan onder HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome. Google raadt die weg aan voor computers die niet aan een Active Directory-domein gekoppeld zijn, en levert een voorbeeldbestand chrome.reg in het Chrome Enterprise-pakket, om aan te passen en te testen vóór je het uitrolt.

Goed om te weten

  • Een extensie die via dit beleid geïnstalleerd is, kan de gebruiker niet verwijderen of uitschakelen. Haal je ze uit de lijst, dan wordt ze verwijderd.
  • Het beleid geldt niet voor incognitovensters.
  • De beperking tot beheerde toestellen (domein, MDM…) geldt voor extensies van buiten de Chrome Web Store. Paperkeep staat in de Chrome Web Store.

4. Microsoft Edge

Met een groepsbeleid (Windows)

  1. Download de beheersjablonen van Microsoft Edge via de pagina Microsoft Edge Enterprise en kopieer msedge.admx (en het .adml-bestand van je taal) naar de map met beleidsdefinities.
  2. Open in de editor Computer Configuration (of User Configuration) › Policies › Administrative Templates › Microsoft Edge › Extensions. Dat zijn de Engelse labels uit de documentatie van Microsoft; een Nederlandstalige Windows vertaalt ze.
  3. Open « Control which extensions are installed silently », schakel het in en voeg de Edge-waarde uit de tabel toe.

Via het register

Sleutel: HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist. Elke extensie is een waarde van het type REG_SZ met de naam 1, 2, 3… Voorbeeld:

SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist\1 = ekoobifejmegpmndflgdcepbldfbegki;https://edge.microsoft.com/extensionwebstorebase/v1/crx

Op Mac

Voorkeurssleutel ExtensionInstallForcelist, als lijst (<array>) met de Edge-waarde uit de tabel.

Goed om te weten

  • Op een Windows-toestel dat niet aan een Active Directory-domein gekoppeld is, kan je alleen extensies uit Edge Add-ons verplicht installeren. Paperkeep staat in Edge Add-ons.
  • De gebruiker kan de extensie niet verwijderen of uitschakelen. Haal je ze uit de lijst, dan wordt ze verwijderd.
  • Het beleid geldt niet in de InPrivate-modus.
  • Op 26/10/2026 is de versie in Edge Add-ons de 1.4.2 (bijgewerkt op 17/10/2026). De toestellen krijgen de volgende versies automatisch via de store.

Firefox heeft eigen bedrijfsregels, die deze pagina niet behandelt.

5. Controleren of het beleid toegepast is

  • Chrome: open chrome://policy, laad het beleid opnieuw en controleer dat de status van de regel « OK » is. Gebruikers moeten Chrome herstarten voor de wijziging werkt.
  • Edge: open edge://policy om de toegepaste regels te zien. Om het groepsbeleid op een toestel meteen te vernieuwen: gpupdate /force, sluit Edge en open het opnieuw.

Een vraag vóór het uitrollen: contact@paperkeep.be. Om Paperkeep aan je klanten voor te stellen: de kit voor boekhouders.

Bronnen, geraadpleegd op 26/10/2026:

  • Google, definitie van het beleid ExtensionInstallForcelist (beleidssjablonen van Chromium);
  • Hulp van Chrome Enterprise: beleid voor apps en extensies (Windows), beleid voor beheerde computers, beleid en Windows-register, controle met chrome://policy;
  • Microsoft Learn: ExtensionInstallForcelist voor Microsoft Edge (bijgewerkt op 09/07/2026) en Microsoft Edge configureren met beleid;
  • Gepubliceerde versie in Edge Add-ons: officiële fiche van Paperkeep in Edge Add-ons.

De namen van beleidsregels en menu's kunnen veranderen met de versies van Chrome, Edge en Windows. Test op één toestel vóór je uitrolt.
